# Fix Round Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 8 bugs in the approved spec (`docs/superpowers/specs/2026-08-01-fix-round-design.md`): version-flag crash, UI freeze on network commands, black color for white-mode bulbs, wrong-device boot resolution, hex normalization, shebang, status keyword sniffing, and a minor-polish bundle.

**Architecture:** A thin async command layer (`sendCmd` returning `tea.Cmd`, results via `commandResultMsg`) replaces all synchronous `wiz.SendCommand` calls inside the Bubble Tea `Update` loop. Status messages carry an explicit level (`statusInfo`/`statusSuccess`/`statusError`) instead of keyword sniffing. Everything else is surgical single-file fixes.

**Tech Stack:** Go 1.25, Bubble Tea v1.3.10, lipgloss v1.1.0. Module name is `wiz-tui`. Build/run target is `./internal` (the main package lives in `internal/`).

## Global Constraints

- Existing tests must stay green after every task: `go test ./...` from repo root.
- Test placement convention: black-box tests live in `tests/<pkg>/` (external package). White-box tests for unexported identifiers go in-package as `internal/ui/*_internal_test.go`.
- One deliberate design point: *stepped* values (brightness, color temp) update the model at dispatch time so rapid keypresses step correctly; *discrete* values (power, color) update only in the command's `onSuccess` callback. Failure is always reported via error-level status.
- Commit after each task. Plain commit messages — no co-author trailers.

```go
// sendCmd sends a device command asynchronously. Empty successMsg and
// failPrefix mark a silent send: no status push, no telemetry.
func sendCmd(ip, port, method string, params map[string]interface{},
	successMsg, failPrefix string, onSuccess func(*model)) tea.Cmd {
	return func() tea.Msg {
		start := time.Now()
		err := wiz.SendCommand(ip, port, method, params)
		return commandResultMsg{
			err:        err,
			elapsed:    time.Since(start),
			onSuccess:  onSuccess,
			successMsg: successMsg,
			failPrefix: failPrefix,
		}
	}
}
```

```go
	case commandResultMsg:
		silent := msg.successMsg == "" && msg.failPrefix == ""
		if !silent {

		}
		if msg.err != nil {
			if !silent {
				m = pushStatus(m, statusError, fmt.Sprintf("%s: %v", msg.failPrefix, msg.err))
			}
			return m, nil
		}
		if msg.onSuccess != nil {
			msg.onSuccess(&m)
		}
		if !silent {
			m = pushStatus(m, statusSuccess, msg.successMsg)
		}
		return m, nil
```

```go
// activeMac returns the MAC for the saved device matching the current target IP.
func activeMac(cfg config.Config) string {
	for _, saved := range cfg.SavedDevices {
```
